About this tracker

What is tracked

AI-run businesses: projects where AI agents do most of the work of building and selling a product. For each one we record revenue, profit, customers, output, traction and how the agents are set up (models, harness, schedule, memory, how much a human does). Trading tools are not covered yet.

Each project is checked once a day (UTC). A project page shows its history, its setup, a timeline of events with links to evidence, and the daily notes from each check.

Numbers come from the project's own public pages, feeds and APIs. Every number links back to the source it came from, on the project page under "Latest reported values."

Project classes

Class is a column and a filter in the same dataset; there is no separate leaderboard. Autonomous (class 4) and AI-operated (class 3) projects have at least two evidenced business functions run by agents and a human role other than co-pilot clicks; class 4 additionally means the human only sets strategy or does nothing and agents monitor or run operations. AI-native (class 2) means the product is AI but people run the company, or we have not yet seen agents run at least two functions. Class is derived from public evidence about agent functions and human role, not typed in. Founders who simply use AI tools are not listed. Class 2 projects can be viewed as a preset filter.

How activity is judged

Activity uses dated evidence: Last-Modified, sitemap and feed dates, GitHub pushes, the source's own update date, recorded events, and detected page changes. The newest dated signal is the last activity. A project is Active when that date is within 7 days, Quiet at 8–30 days, and Dormant after 30 days. A completed project is Ended; three newest readings on different days that are all non-2xx or errors mean Unreachable. With no dated evidence it is Unknown.

The default order groups statuses as Active, Quiet, Unknown, Dormant, Unreachable, Ended; within each group it puts Tranco-listed domains first by traffic rank, then longer active spans, then name. Active span runs from the stated start date, first archived date, or first tracked date to the end date, last activity for Ended or Dormant projects, or the current data date.

Updates (30 d) counts observed page readings whose visible text could be compared with an earlier reading within 3 days; it reports how many changed. It starts when we begin reading and is not backfilled. A page with a live clock or counter can change every day, so dated signals are listed with their kind for readers to judge.

Traffic rank comes from Tranco, a free daily research-grade list of the top 1 million sites. Most small projects are outside it. Traffic rank only separates the few larger sites; it is not a measure of business performance. Revenue is shown with its verification badge, but is not used to order projects.

NanoCorp directory

The NanoCorp page shows weekly snapshots of the platform's public live-business directory. Names, launch dates and revenue captions are reported by NanoCorp, not independently verified by us; these businesses are not registry projects and are separate from this dataset. We read the directory listing only, not each company page. An empty or refreshing directory is treated as a failed collection, so the last successful snapshot stays visible.

What the badges mean

Every number is shown with a badge that says how it was checked. The badge is written out in words so it never depends on color.

Self-reported
The project says so, and nobody independent has confirmed it. This is the weakest level.
Marketplace count
The marketplace that sells the product shows the count publicly (for example "N sold"). It confirms sales, not revenue.
Stripe-verified
The figure has been confirmed against Stripe's records by a third party, not only on the project's say-so.
On-chain
The figure can be read from a public blockchain.
Audited
An independent third party has audited the figure.

A project can move up a level over time. Its project page keeps that history under "Verification history."

Projects run by the tracker's owner

The owner of this tracker also runs an AI business of their own. It is tracked like every other project, but is labeled "Run by the tracker's owner" on its row and page so readers can weigh its numbers. The label does not change the dataset order. The tracker links to it only from its own project page: no banners, ads or featured spots.

Right now, no tracked project is run by the owner.

How the numbers are shown

  • Not reported means the source did not give the number. It is never shown as 0, and we never estimate, fill in or back-date a figure.
  • All-time revenue is net when reported, otherwise gross, and is labeled. It is shown with its verification badge and can be sorted as a column, but it does not decide which projects are listed or their default order.
  • Revenue since tracking began is the latest figure minus the first one we recorded, so projects that started at different times can be compared more fairly.
  • Stale marks a value whose source has not updated in more than 7 days.
  • On charts, a line breaks where more than 3 days have no reported value.
  • Profit is shown only when the project reports it. It is never worked out as revenue minus spend, and it can be negative (shown with a minus sign).
